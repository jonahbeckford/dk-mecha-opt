Experiment environment

The secrets every executor can hold, wherever experiments run: this computer, GitHub Actions or Diskuv SaaS. A person running an experiment never gets them.
Repositories, files, models, data and parameters are in What the mecha may change and read. Each experiment receives them as dk0 run-function arguments.

Secrets

  • CLAUDE_CODE_OAUTH_TOKENFrom Settings, LLMs. Value hiddenThis computer, GitHub, SaaS
  • [NAME]Value hidden. Set [date][This computer, GitHub]
A secret is kept in this computer's key store and copied only to the executors you tick: to GitHub as an Actions secret of the repository that runs the experiments, to Diskuv SaaS into your account's vault. It never goes into the project or a report, and it cannot be read back once saved. "Secrets each step may use", under Scope, says which steps receive each one. Tick Approve each use for a secret that can publish, release or pay for something: every run whose steps receive it waits for you at AUTHORIZE.
