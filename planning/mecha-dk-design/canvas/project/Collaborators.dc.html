Collaborators

People you invite can receive experiments to run and send back results. The study is shared through Diskuv SaaS, signed in as [email].

Invite someone

A collaborator sees the whole hypothesis tree, poses hypotheses, runs the experiments you send them, and can request measurement changes for you to approve. Only you approve experiments, reviews and calibrations.
A collaborator can end up with your full control. What a collaborator writes, such as a hypothesis, a note or an experiment result, is read by the LLMs and coding agents this project uses. Text written to trick an LLM (a prompt injection) can make them act as if you asked: run code with your secrets, change files the mecha may change, or word a request so that you approve it. Invite only people you would trust with this computer. Read the security notes
