Pose a problem or a hypothesis. Both land in one hypothesis tree, and the mecha works the tree in cycles.

Source: Paper I section 2 and design.typ part 4. A problem is a prompt that IDEATE turns into hypotheses. A hypothesis is a proposed change to the system under optimization (SUO), carried as a node with a posterior over the project's loss.

Once per project
Create a project
Declare the SUO (edit surface, measured surface, public spec, boundary), the objective function, the revelations, and a model per role. This is dk0 learn init.
Flow 1
Pose a problem
Free text. At the next IDEATE the mecha breaks it into hypotheses and places each under the node it best refines. Progress is tracked per problem.
Flow 2
Pose a hypothesis
A proposed change, stated directly. It is placed in the tree and checked against the revelations at DROP. Progress is tracked per hypothesis, as its posterior.
One cycle, OBSERVE to PERSIST
Shaded stages are attended: they wait for the human, and are skipped in an unattended window.
  1. OBSERVE
  2. AUTHORIZE
  3. IDEATE
  4. DROP
  5. SELECT
  6. DISPATCH
  7. UPDATE
  8. DECIDE
  9. REVIEW
  10. CALIBRATE
    LLM only
  11. PERSIST
Authorize decisions. AUTHORIZE releases a hypothesis parked for a spend or a revelation. REVIEW signs off a merged change against the spec, or records a spec gap. CALIBRATE approves measurement changes an LLM researched; it exists only when a project assigns one, and anyone can still request a change in project settings.
Observe progress. The stage running now, the experiments DISPATCH runs in isolated worktrees, and each hypothesis's posterior with its width as UPDATE folds results in.
Review outputs. The reports dk0 learn report renders: cycle report, frontier map, scorecard, REVIEW reconciliation, explanation, window report. A run ends when DECIDE adopts a hypothesis.
Decided, and still open
  • Decided: cycles run back to back and stop at the next attended stage.
  • Decided: reports show as rendered Typst pages (SVG or PNG). dk0 writes .typ and spawns a Typst asset for other formats. On the web, Android and iOS, the app renders .typ to SVG itself (queued for dk-engine-opt).
  • Decided: the app uses the dk mark; fonts are Inter, Lato, Ubuntu Mono and Poppins, each shipped with its license text.
  • Decided: the app speaks as to a principal investigator, for software and science alike: "research question" for problem, "revelation" kept as the word for revelations, one New project form.
  • Decided: changes to how results are measured are requests, applied one at a time between cycles, undone automatically if they fail to apply or re-baseline, and left to you if their later check fails.
  • Decided: the human steers only through the named acts (pose a problem or hypothesis, add a revelation, authorize or keep parked, stop after a stage). No free-text box.
